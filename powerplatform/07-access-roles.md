# 07 · สิทธิ์ตามบทบาท (Role-based Access)

> **ข้อจำกัดจริงหน้างาน:** พนักงานหน้างาน (Staff) **ไม่มีบัญชี M365 รายคน** — มีแค่ **เมลกลางทีม** (บัญชีเดียวใช้ร่วมกัน)
> ดังนั้น "ล็อกอินรายคนแล้วกรองงานของฉันอัตโนมัติ" **ใช้กับ Staff ไม่ได้** — ต้องแยกเป็น 2 เส้นทาง

## สรุปโมเดล 2 เส้นทาง

| กลุ่ม | มีบัญชี M365? | เข้าได้ยังไง | ดู | วันที่ | แก้ไข |
|---|---|---|---|---|---|
| **Admin / Mgr / Duty / Sup** | ✅ รายคน | **ล็อกอินบัญชีตัวเอง** (รู้บทบาทจาก sign-in) | ทุกทีม ทุกคน | **ทุกวัน** ไม่จำกัด | ✅ |
| **พนักงาน (Staff)** | ❌ มีแต่เมลกลางทีม | เปิด **ลิงก์อ่านอย่างเดียว** ด้วยบัญชีกลาง / จอรวม | ทีมตัวเอง + ค้นงานตัวเองด้วย**รหัส** | ย้อนหลังได้ทุกวัน + ล่วงหน้า **ถึงพรุ่งนี้ (วันนี้+1)** | ❌ อ่านอย่างเดียว |

หัวใจคือ: **สิทธิ์แก้ไข = ผูกกับบัญชี M365 (sign-in)** ส่วน **Staff ดูผ่านลิงก์กลาง + ค้นด้วยรหัสแทนการล็อกอิน**

---

## เส้นทาง A — Sup/Duty/Mgr/Admin (มีบัญชี → แก้ไข + ทุกวัน)

ทำงานบน **Excel Online บน SharePoint เดิม** (มีสิทธิ์อยู่แล้ว ไม่ต้องลงทุนเพิ่ม):
- ให้สิทธิ์ **Edit** บนโฟลเดอร์/ไฟล์ PAS เฉพาะกลุ่มนี้ (SharePoint → Manage Access → เพิ่มอีเมล 4 กลุ่มนี้แบบ Edit)
- เห็นและแก้ได้ทุกวัน ไม่มีเพดานวัน
- Dashboard / Coverage / By Person / By Team สร้างด้วย Office Script (ที่ทำไว้แล้ว) — กลุ่มนี้กด Run เองได้

> ถ้าต้องการแยกบทบาทละเอียด (เช่น Sup แก้ได้เฉพาะทีมตัวเอง) ค่อยยกระดับเป็น **Power Apps + รายชื่อ `Roles`** ภายหลัง — ตอนนี้ "สิทธิ์ Edit บน SharePoint" พอสำหรับงานภายใน

## เส้นทาง B — Staff (ไม่มีบัญชีรายคน → อ่านอย่างเดียว + ค้นด้วยรหัส)

เพราะไม่มีบัญชีรายคน จึง **ระบุตัวตนไม่ได้** → ใช้ "ค้นด้วยรหัส" แทน และ **ตัดข้อมูลวันอนาคตเกินพรุ่งนี้ออกตั้งแต่ต้นทาง** (กันเห็นแบบร่างที่ยังไม่ fix)

**วิธีทำ(ฟรี ไม่ต้องขอ consent):**
1. **Office Script สร้างชีต "Staff View"** — คัดเฉพาะ **วันที่ ≤ วันนี้+1** (อดีตทั้งหมด + ถึงพรุ่งนี้) ตัดวันอนาคตไกลทิ้ง
   - มีคอลัมน์ `รหัส / ชื่อ / ทีม / กะ / ไฟลท์-งาน` → Staff ใช้ **AutoFilter พิมพ์รหัสตัวเอง** = "งานของฉัน"
   - กรองทีมด้วยคอลัมน์ `ทีม` ได้เช่นกัน
2. **แชร์แบบ View-only** ไฟล์/ชีตนี้ไปที่ **เมลกลางทีม** (SharePoint → Manage Access → Can view)
   - เปิดบนจอรวมหน้างาน / มือถือทีม ด้วยบัญชีกลาง
3. (ทางเลือก) ตั้ง **Power Automate** รัน Staff View ใหม่อัตโนมัติทุกเช้า → ข้อมูลสดเสมอ

> **เพดานวัน Today+1 บังคับที่ "ข้อมูล" ไม่ใช่ที่ "สิทธิ์"** — Staff View มีแค่วัน ≤ พรุ่งนี้ จึงดูวันอนาคตไกลไม่ได้ (เพราะไม่มีในชีต) ส่วนย้อนหลังดูได้ทุกวันตามต้องการ

---

## ⚠ หมายเหตุความปลอดภัย / PDPA (สำคัญ)

- **บัญชีกลาง = ใครถือรหัสผ่านก็เห็นทั้งทีม** — ไม่มีการแยกรายคนจริง (เพราะไม่ล็อกอินรายคน)
  → เหมาะกับ "ดูภายในทีม" เท่านั้น · **ห้ามแชร์ลิงก์นี้ออกสู่สาธารณะ** (มีชื่อ/กะ/ไฟลท์ = ข้อมูลส่วนบุคคล)
- การ "ค้นด้วยรหัส" **ไม่ใช่การยืนยันตัวตน** — กันแค่ความสะดวก ไม่ได้กันการแอบดูของคนอื่นในทีม
- อยากได้สิทธิ์รายคนจริง ต้องให้พนักงาน **มีบัญชี M365 ของตัวเอง** (ค่าใช้จ่าย/จัดการเพิ่ม) แล้วค่อยกลับไปใช้โมเดล login + `User().Email`

## ถ้าวันหนึ่ง Staff ได้บัญชี M365 รายคน (อนาคต)
ค่อยสลับเส้นทาง B เป็น **Power Apps + ล็อกอินรายคน**:
```powerapps
Set(varUser, Lower(User().Email));
Set(varRole, Coalesce(LookUp(Roles, Lower(Email)=varUser, Role), "Staff"));
Set(varPriv, varRole in ["Admin","Mgr","Duty","Sup"]);
Set(varMe,  LookUp(Employees, Lower(Email)=varUser));
Set(varMaxDate, If(varPriv, DateAdd(Today(),365), DateAdd(Today(),1)));
// Gallery: varPriv → ทุกคน · ไม่ใช่ → emp_code=varMe.emp_code || team=varMe.team
```
(เก็บไว้เป็นแผนสำรอง — ยังใช้ไม่ได้ตอนนี้เพราะ Staff ไม่มีบัญชี)
