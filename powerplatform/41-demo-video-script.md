# 41 · สคริปต์ + สตอรี่บอร์ดคลิปสอนใช้งาน (พร้อมบทพากย์ไทย)

เอาไป **อัดหน้าจอจริง** แล้วพากย์ตามบท (หรือใช้ TTS) · รวม ~4–6 นาที · แบ่งเป็นฉากสั้น ตัดต่อง่าย
> ผมสร้างไฟล์วิดีโอ/เสียงให้ไม่ได้ — เอกSคริปต์นี้ไว้ให้คนอัด (หรือ Claude in Chrome เปิดแอปแล้วอัด) ทำตาม

## อุปกรณ์/วิธีอัด (เลือกอย่างใดอย่างหนึ่ง)
- **Clipchamp** (มากับ Windows) — อัดหน้าจอ + ไมค์ + ใส่ **AI voiceover ไทย** ได้ในตัว (ไม่ต้องพากย์เอง)
- **PowerPoint → Record** / **Xbox Game Bar (Win+G)** / **OBS** — อัดหน้าจอ + ไมค์
- **เสียงพากย์:** พูดเองตามบท · หรือ TTS ไทย (Clipchamp / Azure AI Speech / Edge Read aloud) แล้ววางทับ
- อัดบน **มือถือ** (จอที่พนักงานใช้จริง) หรือเปิดแอปบนเว็บแล้วอัดจอคอม

## เตรียมก่อนอัด
- ใช้ **ข้อมูลทดสอบ** (ไซต์ทดสอบ doc 35) ไม่ให้ชื่อ/รหัสคนจริงโผล่ (PDPA)
- เตรียมบัญชี 3 แบบไว้สลับโชว์: **Admin · Editor(หัวหน้า) · พอตเตอร์(Kiosk+PIN)**
- ซูม/ขยายตัวอักษรให้เห็นชัดบนคลิป

## ฉาก (Scene) · สิ่งที่โชว์ · บทพากย์

### 0 · เปิด (0:00–0:15)
- **จอ:** โลโก้/ชื่อแอป "PAS · ระบบจัดกำลังพล PSA-HKT"
- **พากย์:** "สวัสดีครับ คลิปนี้จะพาดูวิธีใช้ระบบจัดกำลังพล PAS ของ PSA ภูเก็ต ตั้งแต่เข้าสู่ระบบ ดูงานของตัวเอง ไปจนถึงการจ่ายงานพอตเตอร์วีลแชร์"

### 1 · เข้าสู่ระบบ (0:15–0:55)
- **จอ:** หน้า scrHome → โชว์ badge สิทธิ์ · แล้วสลับโชว์ scrSignIn (เลือกชื่อ + ใส่ PIN)
- **พากย์:** "หัวหน้างานและแอดมินเข้าด้วยบัญชีบริษัท (M365) ระบบจะรู้สิทธิ์เองจากอีเมล · ส่วนพนักงานและพอตเตอร์ที่ไม่มีบัญชี ให้เข้าที่เครื่องกลาง เลือกชื่อตัวเอง แล้วใส่ PIN สี่ถึงหกหลัก · ครั้งแรกใช้รหัสพนักงานเป็น PIN แล้วระบบจะให้ตั้งใหม่"
- **เน้น:** PIN ผิด 5 ครั้งล็อก 5 นาที · กดรูปกุญแจเพื่อออกจากระบบทุกครั้งที่ใช้เสร็จ

### 2 · เมนูหลักตามสิทธิ์ (0:55–1:25)
- **จอ:** scrHome การ์ดเมนู → ชี้ badge "แก้ไขได้ / ดูอย่างเดียว / ADMIN"
- **พากย์:** "หน้าเมนูจะแสดงเฉพาะสิ่งที่คุณมีสิทธิ์ · หัวหน้าเห็นปุ่มแก้ไข · พนักงานทั่วไปดูได้อย่างเดียว · ส่วนพอตเตอร์จะเห็นเฉพาะงานวีลแชร์ · เมนูจัดการระบบเปิดให้แอดมินเท่านั้น"

### 3 · งานของฉัน + รับทราบ (1:25–2:15)
- **จอ:** scrMe → แท็บ "งานไฟลท์" → กด **รับทราบ** งานหนึ่ง (ปุ่มเปลี่ยนเป็น ✓)
- **พากย์:** "ทุกคนดูงานของตัวเองได้ที่หน้า งานของฉัน · ก่อนเริ่มงานให้กด รับทราบ ทุกงาน · ระบบจะเตือนถ้ายังมีงานที่ยังไม่รับทราบ โดยเฉพาะเคสวีลแชร์กับงานซัพพอร์ท"

### 4 · ตารางเวร / แลกเวร / ลา (2:15–3:00) — สิทธิ์ Editor
- **จอ:** scrRoster → เปิดโหมดแลกเวร เลือก A/B กดยืนยัน · โหมดลา เลือกวัน+ประเภท
- **พากย์:** "หัวหน้าทีมดูตารางเวรทั้งทีมได้ · แลกเวรได้สูงสุดสามครั้งต่อเดือน ระบบคุมโควตาให้ · บันทึกวันลา SL/VL/BL ได้ในหน้าเดียว ระบบเช็กสิทธิ์วันลาให้อัตโนมัติ · และเปลี่ยนกะจากชุดกะมาตรฐานได้"

### 5 · มอบหมายงานต่อไฟลท์ (3:00–3:40) — Editor
- **จอ:** scrAssign → เลือกไฟลท์ → กดช่องลงตำแหน่ง · (ถ้ามี) ปุ่มจัดอัตโนมัติ
- **พากย์:** "หน้ามอบหมายงานจะลงคนตามตำแหน่งของแต่ละไฟลท์ · กดจัดอัตโนมัติให้ระบบเติมให้ก่อน แล้วปรับมือทีหลังได้ · พนักงานทั่วไปจะเห็นเฉพาะงานของตัวเอง"

### 6 · จ่ายงานพอตเตอร์วีลแชร์ (3:40–4:40) — จุดเด่น
- **จอ:** scrLP โหมด LP → เลือกเคส + เลือกพอตเตอร์ → กด "มอบหมาย" · แล้วสลับเป็นเครื่องพอตเตอร์ → กด **รับเคส/รับทราบ → เริ่มงาน → จบงาน**
- **พากย์:** "LP เลือกเคสวีลแชร์ที่รอจ่าย เลือกพอตเตอร์แล้วกดมอบหมาย · ระบบจะยังไม่เริ่มงานจนกว่าพอตเตอร์จะกดรับทราบที่เครื่องของตัวเอง · จากนั้นกดเริ่มงาน และจบงานเมื่อส่งผู้โดยสารถึงที่ · ทุกสถานะบันทึกเวลาจริงให้อัตโนมัติ"
- **เน้น:** จ่ายงานตามคิวเคสน้อยสุดก่อน · เตือนถ้ารับทราบช้าเกิน 5 นาที

### 7 · แดชบอร์ด + ตรวจ OT (4:40–5:20)
- **จอ:** scrDay (ตัวเลขคนทำงาน/OT/ไฟลท์/ยังไม่รับทราบ + ต่อทีม) · หน้า ตรวจ OT
- **พากย์:** "หน้าแดชบอร์ดสรุปภาพรวมรายวัน · จำนวนคนทำงาน ชั่วโมง OT ไฟลท์ และงานที่ยังไม่รับทราบ แยกตามทีม · ส่วนหน้าตรวจ OT ดูชั่วโมง OT ที่ขอจริงย้อนหลังได้ตามช่วงที่มีข้อมูล"

### 8 · ปิด (5:20–5:40)
- **จอ:** กลับ scrHome · โลโก้
- **พากย์:** "เท่านี้ก็พร้อมใช้งานแล้วครับ · ใช้เสร็จอย่าลืมกดออกจากระบบทุกครั้ง · หากพบปัญหาแจ้งแอดมินได้เลย ขอบคุณครับ"

## เคล็ดตัดต่อ
- ตัดเป็นคลิปสั้นต่อฉาก → ถ้าอยากทำ "คลิปสั้นเฉพาะเรื่อง" (เช่น เฉพาะพอตเตอร์) ใช้ฉาก 1 + 3 + 6
- ใส่ **ข้อความบนจอ (caption)** ย้ำปุ่มสำคัญ: "กดรับทราบก่อนเริ่มงาน" · "แลกเวร ≤ 3 ครั้ง/เดือน"
- ความยาวเหมาะกับดูบนมือถือ: ตอนละ 1–2 นาที ดีกว่าคลิปยาวเดียว

> อยากได้ **เวอร์ชันสั้นเฉพาะพอตเตอร์** (1–2 นาที) หรือ **บทพากย์แยกไฟล์ (.txt) สำหรับใส่ TTS** บอกได้ ผมแยกให้
