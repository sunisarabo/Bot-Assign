# ⚠️ screens/*.pa.yaml — ฉบับร่าง (DRAFT) อย่าวางทับหน้าในแอป

ไฟล์ `.pa.yaml` ในโฟลเดอร์นี้เป็น **ฉบับร่าง/อ้างอิง** ที่สร้างจากพิมพ์เขียว — **สั้นกว่าหน้าจริงในแอปมาก** และบางไฟล์อ้างสคีมาที่แอปยังไม่ได้ใช้

| ไฟล์ | สถานะ | อย่าวางทับเพราะ |
|---|---|---|
| `scrHome.pa.yaml` | ร่าง | หน้าจริงมีการ์ดแอดมิน/เครื่องกลาง/หน้ากั้น ครบกว่า · ร่างนี้อ้าง `varMe.emp_code` |
| `scrMe.pa.yaml` | ร่าง | หน้าจริง ~750 บรรทัด มีมุมมองรายสัปดาห์/ช่องรหัส/หน้ากั้นเครื่องกลาง · ร่างอ้าง `ack_by` (ไม่มีใน PAS_Assignment) |
| `scrLP.pa.yaml` | ร่าง · **สคีมาไม่ตรง** | หน้าจริงใช้ **`PAS_Porter` (lp_*)** · ร่างนี้ใช้ `pas_wc_*` ที่ยังไม่มีในแอป → ทั้งหน้าแดง |
| `scrDay.pa.yaml` | ร่าง | หน้าจริง ~11,400 บรรทัด (Porter/Support/Auto Assign/ตรวจ Assign/Gantt/Util/SLA/Pre-WC + สลับ view มือถือ) · ร่างมีแค่ tiles+ต่อทีม |
| `scrSignIn` / `scrAdminRoles` | — | **ไม่มีในโฟลเดอร์** · ใช้ฉบับที่ build ในแอป (firstPIN) เป็นจริง |

> ฉบับจริงที่วางลงแอปแล้ว = ไฟล์ที่เจ้าของส่ง (`scrSignIn+scrAdminRoles-firstPIN`, `scrAssign-doc32-own-jobs`)
> ใช้ร่างเหล่านี้เป็น "ไอเดีย/สไตล์ (token T.*)" เท่านั้น — การแก้หน้าจริงให้ทำบนหน้าจริง ทีละจุด

## หมายเหตุที่พบ (กันพลาดซ้ำ)
- **Label แบบ classic ไม่มี `RadiusTopLeft/…`** → อย่าใส่ Radius ใน Label (ใช้ Rectangle รองพื้นถ้าต้องการมุมโค้ง)
- Porter/WC จริง = ตาราง **`PAS_Porter` (lp_*)** — เอกสาร `wc-01..10` (pas_wc_*) เป็นดีไซน์คู่ขนาน ต้อง **map เป็น lp_* ของจริงก่อนใช้**
- `PAS_Users` ควรมี **`emp_code`** เพื่อผูก M365 ↔ รหัสพนักงานตรง ๆ (เลิกเดารหัสจากอีเมล)
