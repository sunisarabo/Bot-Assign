# คู่มือการใช้งานระบบ PAS

**Passenger Services Manpower System · PSA ท่าอากาศยานภูเก็ต**

ระบบจัดกำลังพลฝ่ายบริการผู้โดยสาร — ตารางเวร มอบหมายงานต่อเที่ยวบิน รับทราบงาน และจ่ายงานพอตเตอร์วีลแชร์ ใช้ได้ทั้งบนคอมพิวเตอร์และมือถือ

> ใช้ข้อมูลทดสอบในการฝึกใช้งาน และตรวจสอบข้อมูลทุกครั้งก่อนกดยืนยัน

\newpage

# บทที่ 1 · การเข้าสู่ระบบ (Login)

## การเข้าสู่ระบบมี 2 แบบ
| กลุ่มผู้ใช้ | วิธีเข้า |
|---|---|
| หัวหน้างาน · ผู้ดูแลระบบ (และผู้มีบัญชีบริษัท) | บัญชี **Microsoft 365** ของบริษัท |
| พนักงาน · พอตเตอร์ (ไม่มีบัญชี) | **เลือกชื่อ + ใส่ PIN** ที่เครื่องกลาง |

## แบบ A · บัญชี Microsoft 365
1. เปิด **ลิงก์แอป PAS** ที่หน่วยงานแจก (คอม/มือถือ)
2. ใส่ **อีเมลบริษัทและรหัสผ่าน** (เหมือนเข้า Outlook/Teams)
3. เข้าแล้วเห็นเมนูหลัก + ป้ายสิทธิ์มุมขวาบน: **ADMIN · หลังบ้าน** / **แก้ไขได้** / **ดูอย่างเดียว**

## แบบ B · เลือกชื่อ + PIN (เครื่องกลาง)
1. พิมพ์ **รหัสพนักงานหรือชื่อ อย่างน้อย 2 ตัว** ในช่องค้นหา
2. **แตะเลือกชื่อ** ของตัวเอง
3. ใส่ **PIN 4–6 หลัก** แล้วกด **เข้าใช้งาน**

**ครั้งแรก:** ใช้ **รหัสพนักงานเป็น PIN** → ระบบบังคับตั้ง PIN ใหม่ (4–6 หลัก · ห้ามรหัสพนักงาน/เลขเรียง/เลขซ้ำ · ใส่ 2 ครั้งให้ตรง)

**กฎ:** ใส่ PIN ผิด 5 ครั้ง → ล็อก 5 นาที · ลืม PIN → แจ้งผู้ดูแลระบบ

## ออกจากระบบ
ใช้เสร็จ **กดปุ่มกุญแจ 🔒 ออกจากระบบทุกครั้ง** (บนเครื่องกลางสำคัญมาก ไม่งั้นคนถัดไปใช้ในชื่อท่าน)

## สิทธิ์ตามตำแหน่ง
| ตำแหน่ง | ทำได้ |
|---|---|
| Director · Manager · Assistant Manager · Supervisor | ดู **และแก้ไข** |
| Senior · Agent · Officer | **ดูอย่างเดียว** |
| Porter | เห็นเฉพาะ **งานวีลแชร์** |
| ผู้ดูแลระบบ (อีเมลที่กำหนด) | จัดการระบบ/สิทธิ์/PIN |

# บทที่ 2 · งานของฉัน + การรับทราบ

หน้า **งานของฉัน** แสดงงานที่ได้รับมอบหมายในวันนั้นของตัวเอง

## ขั้นตอน
1. เปิดการ์ด **งานของฉัน** จากเมนูหลัก
2. ดูรายการงาน (เที่ยวบิน · ตำแหน่ง · เวลา)
3. **กดปุ่ม "รับทราบ"** ทุกงาน ก่อนเริ่มปฏิบัติงาน — ปุ่มจะเปลี่ยนเป็น ✓ รับทราบแล้ว

## สิ่งที่ควรรู้
- แถบด้านบนเตือนจำนวน **งานที่ยังไม่รับทราบ** โดยเฉพาะ **เคสวีลแชร์/งานซัพพอร์ท** (งานเร่งด่วน)
- การกดรับทราบ = ยืนยันว่าได้รับงานและพร้อมปฏิบัติแล้ว (ต้องรับทราบก่อนจึงเริ่มงานได้)
- **พอตเตอร์:** กดปุ่ม **♿ พอตเตอร์** เพื่อไปหน้ารับงานวีลแชร์ (ดูบทที่ 5)

\newpage

# บทที่ 3 · ตารางเวร · แลกเวร · การลา

หน้า **ตารางเวร (Roster)** แสดงเวรของทั้งทีม (คน × วัน)

## ดูตารางเวร
1. เลือก **ทีม** และ **เดือน** แล้วกด **โหลดตาราง**
2. ช่องแต่ละวันแสดงกะ (เช่น เช้า/บ่าย/ดึก) · OFF = วันหยุด · สีต่างบอกสถานะ (ลา/OT)

## แลกเวร (เฉพาะหัวหน้า)
1. กด **โหมดแลกเวร**
2. เลือก **คน A + วัน** และ **คน B + วัน** → กด **ยืนยันแลก**
3. แลกได้สูงสุด **3 ครั้ง/เดือน/คน** — ระบบคุมโควตาให้อัตโนมัติ

## บันทึกการลา
1. กด **โหมดลา** → เลือก **คน · ช่วงวัน · ประเภท** (ลาป่วย SL · พักร้อน VL · ลากิจ/อื่น ๆ BL)
2. กด **บันทึก** — ระบบตรวจสิทธิ์วันลาคงเหลือและเตือนถ้าเกินสิทธิ์/ลาติดกันเกินกำหนด

## เปลี่ยนกะ
กด **เปลี่ยนกะ** → เลือกคน · วัน · กะจากชุดกะมาตรฐาน → บันทึก

> การแลกเวรและการลา ต้องเป็นไปตามที่หน่วยงานอนุมัติ

# บทที่ 4 · มอบหมายงานต่อเที่ยวบิน + จัดการเที่ยวบิน

## มอบหมายงาน (Assignment)
1. เลือก **ทีม + วัน** แล้วกด **โหลด**
2. เห็น **งานของทั้งทีมในวันนั้น** — เพื่อนร่วมทีมและผู้ที่ทำเที่ยวบินเดียวกัน
3. **(เฉพาะหัวหน้า)** กดที่ช่องเพื่อ **ลงคนในตำแหน่ง** ของเที่ยวบิน · หรือกด **จัดอัตโนมัติ** ให้ระบบเติมก่อนแล้วปรับมือ
4. พนักงานทั่วไป **ดูได้** แต่แก้ไม่ได้

## เพิ่ม / แก้ไข / ยกเลิกเที่ยวบิน (เฉพาะหัวหน้า)
ที่หน้า **ไฟลท์**:
- **เพิ่มเที่ยวบินใหม่** → ขึ้นป้าย ADDED
- **แก้เวลา STA/STD** → ขึ้นป้าย CHANGED
- **ยกเลิก** → ขึ้นป้าย CANCELLED (ขีดฆ่า)

ระบบจะอัปเดตหน้ามอบหมายงานและแดชบอร์ดตามให้ · **ตรวจข้อมูลก่อนยืนยันทุกครั้ง**

\newpage

# บทที่ 5 · พอตเตอร์ / วีลแชร์

## ฝั่ง LP (จ่ายงาน — เฉพาะหัวหน้า/LP)
1. เปิดหน้า **LP จ่ายงาน Porter**
2. เลือก **เคสที่รอจ่าย** + เลือก **พอตเตอร์** → กด **มอบหมาย**
3. ระบบจ่ายงานตามคิว (ผู้รับเคสน้อยสุดก่อน) · เตือนถ้ารับทราบช้าเกิน 5 นาที

## ฝั่งพอตเตอร์ (รับงาน)
เข้าโหมดพอตเตอร์ (จาก "♿ พอตเตอร์" ในงานของฉัน หรือปุ่มโหมดพอตเตอร์ที่หน้าเข้าสู่ระบบ)
1. **รับเคส / รับทราบ** — กดเมื่อได้รับงาน (ต้องรับทราบก่อนเริ่ม)
2. **เริ่มงาน** — เมื่อเริ่มพาผู้โดยสาร (บันทึกเวลารับ)
3. **จบงาน** — เมื่อส่งผู้โดยสารถึงที่หมาย (บันทึกเวลาส่ง)

ทุกสถานะบันทึกเวลาจริงอัตโนมัติ · สถานะไม่ย้อนหลัง (รับทราบ → เริ่ม → จบ)

\newpage

# บทที่ 6 · สำหรับผู้ดูแลระบบ (Admin)

## จัดการสิทธิ์ผู้ใช้ / PIN
หน้า **จัดการระบบ** (เฉพาะแอดมิน):
- เลือกผู้ใช้ → เปลี่ยน **role**: Admin / Editor / Viewer / Porter / Kiosk
- **เพิ่มผู้ใช้ M365** (อีเมล + role ตามตำแหน่ง)
- **ตั้ง/รีเซ็ต PIN** ให้พนักงานที่ใช้เครื่องกลาง
- **สิทธิ์ Admin จำกัดเฉพาะอีเมลที่กำหนดไว้เท่านั้น**

กำหนด role ตามตำแหน่ง: Director/Manager/Asst.Manager/Supervisor = **Editor** · Senior/Agent/Officer = **Viewer** · Porter = **Porter**

## ชั่วโมงทำงาน / OT · ตรวจ OT
- หน้า **ชม.ทำงาน/OT** — สรุปรายสัปดาห์ต่อคน · เตือนสีแดงเมื่อเกิน **48 ชม./สัปดาห์** หรือ **OT 36 ชม.**
- หน้า **ตรวจ OT** — ดูชั่วโมง OT ที่ขอจริงย้อนหลังตามช่วงที่มีข้อมูล

## ข้อมูล · สำรอง · นำเข้า/ส่งออก
- เปิด **Version history** ของทุกลิสต์ + ตั้ง **Daily Backup** (สำรองรายวัน)
- Import/Export ข้อมูลได้จากหน้าแอดมิน (ก่อนนำเข้าก้อนใหญ่ ให้สำรองก่อนเสมอ)
- ทดลองใช้บน **ไซต์ทดสอบ** ก่อนทำกับข้อมูลจริง
