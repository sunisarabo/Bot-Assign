# คู่มือการใช้งานระบบ PAS — บทที่ 1: การเข้าสู่ระบบ (Login)

ระบบ **PAS · Passenger Services Manpower System** (PSA ท่าอากาศยานภูเก็ต)
บทนี้อธิบายวิธี **เข้าสู่ระบบ** สำหรับผู้ใช้ทุกกลุ่ม

---

## การเข้าสู่ระบบมี 2 แบบ (ตามกลุ่มผู้ใช้)

| กลุ่มผู้ใช้ | วิธีเข้า | เข้าที่ |
|---|---|---|
| หัวหน้างาน · ผู้ดูแลระบบ (และพนักงานที่มีบัญชีบริษัท) | **บัญชี Microsoft 365** ของบริษัท | เปิดลิงก์แอปบนคอม/มือถือ |
| พนักงาน · พอตเตอร์ (ไม่มีบัญชีบริษัท) | **เลือกชื่อ + ใส่ PIN** | เครื่องกลางหน้างาน / มือถือที่เปิดไว้ |

---

## แบบ A · เข้าด้วยบัญชี Microsoft 365 (หัวหน้า/แอดมิน)

1. เปิด **ลิงก์แอป PAS** (ที่หน่วยงานแจกให้) บนเบราว์เซอร์หรือแอป Power Apps บนมือถือ
2. ถ้ายังไม่ได้ล็อกอิน M365 ระบบจะให้ **ใส่อีเมลบริษัทและรหัสผ่าน** (เหมือนเข้า Outlook/Teams)
3. เข้าแล้วจะเห็น **หน้าเมนูหลัก** พร้อมป้ายบอกสิทธิ์มุมขวาบน
   - **ADMIN · หลังบ้าน** — ผู้ดูแลระบบ
   - **แก้ไขได้** — หัวหน้างาน (แก้ตารางเวร/มอบหมายงาน/ไฟลท์ได้)
   - **ดูอย่างเดียว** — ดูได้ แก้ไม่ได้

> ระบบรู้สิทธิ์จากอีเมลโดยอัตโนมัติ ไม่ต้องตั้งค่าเพิ่ม

---

## แบบ B · เข้าด้วยการเลือกชื่อ + PIN (พนักงาน/พอตเตอร์ · เครื่องกลาง)

ใช้กับ **เครื่องกลางหน้างาน** หรือมือถือที่เปิดแอปค้างไว้

### ขั้นตอน
1. ที่หน้าเข้าสู่ระบบ ช่องค้นหา **พิมพ์รหัสพนักงานหรือชื่อ อย่างน้อย 2 ตัวอักษร** (เช่น `2304` หรือ `Nawa`)
2. **แตะเลือกชื่อ** ของตัวเองจากรายการ
3. ใส่ **PIN 4–6 หลัก** แล้วกด **เข้าใช้งาน**
4. เข้าแล้วจะไปที่หน้า **งานของฉัน** (พอตเตอร์กด "โหมดพอตเตอร์" เพื่อไปหน้ารับงานวีลแชร์)

### การใช้งานครั้งแรก (ตั้ง PIN)
- ครั้งแรก **ใช้รหัสพนักงานเป็น PIN** (เช่น รหัส `2304` → ใส่ `2304`)
- ระบบจะบังคับ **ตั้ง PIN ใหม่** ทันที:
  - PIN ใหม่ = **ตัวเลข 4–6 หลัก**
  - **ห้าม**ใช้รหัสพนักงาน · เลขเรียง (1234) · เลขซ้ำ (1111)
  - ใส่ PIN ใหม่ 2 ครั้งให้ตรงกัน แล้วกด **บันทึก PIN และเข้าใช้งาน**
- ครั้งต่อไปใช้ **PIN ใหม่** ที่ตั้งไว้

### กฎความปลอดภัย
- ใส่ PIN **ผิด 5 ครั้ง → ล็อก 5 นาที** (รอครบแล้วลองใหม่)
- **ลืม PIN** → ติดต่อผู้ดูแลระบบให้รีเซ็ตให้
- การค้นด้วยชื่อ/รหัส **ไม่ใช่การยืนยันตัวตนเข้มงวด** → อย่าบอก PIN กับคนอื่น

---

## การออกจากระบบ (สำคัญมากบนเครื่องกลาง)
- ใช้งานเสร็จ **กดปุ่มรูปกุญแจ 🔒 ออกจากระบบ ทุกครั้ง**
- ถ้าไม่ออก คนถัดไปจะใช้งานในชื่อของท่าน → งานผิดคน
- "เปลี่ยนผู้ใช้" บนหน้าเมนู = ออกแล้วให้คนถัดไปเลือกชื่อ+PIN ใหม่

---

## สิทธิ์ตามตำแหน่ง (รู้ไว้ว่าตัวเองเห็น/ทำอะไรได้)
| ตำแหน่ง | เห็น/ทำได้ |
|---|---|
| Director · Manager · Assistant Manager · Supervisor | ดู **และแก้ไข** ตามฟังก์ชัน |
| Senior · Agent · Officer | **ดูอย่างเดียว** |
| Porter (พอตเตอร์) | เห็นเฉพาะ **งานวีลแชร์** |
| ผู้ดูแลระบบ (เฉพาะอีเมลที่กำหนด) | จัดการระบบ/สิทธิ์/PIN |

---

## ปัญหาที่พบบ่อย (ล็อกอิน)
| อาการ | วิธีแก้ |
|---|---|
| หาชื่อตัวเองไม่เจอในรายการ | พิมพ์ให้ครบ ≥2 ตัว · ถ้ายังไม่เจอ แจ้งแอดมิน (อาจยังไม่ได้เพิ่มชื่อ) |
| ใส่ PIN แล้วขึ้น "PIN ไม่ถูกต้อง" | ครั้งแรกต้องใช้ **รหัสพนักงาน** เป็น PIN · ถ้าเคยตั้งแล้วลืม → แจ้งแอดมินรีเซ็ต |
| ขึ้น "ถูกล็อก 5 นาที" | ใส่ผิดครบ 5 ครั้ง รอ 5 นาทีแล้วลองใหม่ |
| เข้าได้แต่เมนูน้อย/แก้ไม่ได้ | เป็นสิทธิ์ "ดูอย่างเดียว" ตามตำแหน่ง · ต้องการสิทธิ์เพิ่ม แจ้งแอดมิน |
| หน้า "เครื่องกลาง" ขึ้นว่าใช้ไม่ได้ | เครื่องนั้นต้องล็อกอินด้วยบัญชีเครื่องกลาง (Kiosk) ก่อน — แจ้งแอดมิน |
| เข้าด้วย M365 แต่สิทธิ์ไม่ถูก | แจ้งแอดมินตรวจ role ในเมนูจัดการระบบ |
