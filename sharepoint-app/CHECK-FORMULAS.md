## ติดตั้ง (ครั้งเดียว)
เปิดไฟล์เวรใดก็ได้ใน Excel บนเว็บ → **Automate → New Script** → วาง `check-formulas.ts` → Save ชื่อ **`ตรวจสูตรไฟล์เวร`**
→ กด **… → Share** (Share with everyone in this workbook ไม่จำเป็น — สคริปต์อยู่ใน OneDrive ของคนสร้าง ให้ทีม Admin แชร์ให้หัวหน้าทีมผ่าน Automate → All scripts)

## ใช้งาน
1. เปิดไฟล์เวรของวันนั้น → **Automate → ตรวจสูตรไฟล์เวร → Run**
2. ช่อง `mode`: เว้นว่าง / `check` = **ตรวจอย่างเดียว** (ไม่แก้ไฟล์) · `fix` = **ตรวจ + ซ่อม**
3. ดูแท็บ **`ตรวจสูตร`** — สถานะ `แก้แล้ว` / `ต้องตรวจเอง` / `แก้ได้ (โหมด fix)`
4. แถว `ต้องตรวจเอง`: แก้ตามคำแนะนำ (เช่น เพิ่มรหัสกะในแท็บ ShiftDB) แล้วรันซ้ำ
5. ลบแท็บ `ตรวจสูตร` ได้ (หรือปล่อยไว้ — รันใหม่จะเขียนทับ)

> แนะนำ: รัน **check** ก่อนทุกครั้ง · ใช้ **fix** กับไฟล์ที่ทีมส่งแล้ว ก่อน/หลังนำเข้าก็ได้ (ตัวนำเข้า PAS อ่านเวลา/ชม.จาก ShiftDB และช่วงเวลาเองอยู่แล้ว สูตรที่หายจึงไม่ทำให้ยอดใน PAS ผิด แต่ทำให้ไฟล์ที่ทีมดูผิด)
> เวอร์ชันไฟล์ใน SharePoint/OneDrive ย้อนกลับได้ (File → Info → Version history) ถ้าต้องการยกเลิกการซ่อม
